☁️ Hướng dẫn Tạo Máy Ảo (VPS / Docker) để Livestream 24/7

Để hệ thống chạy nhiều luồng song song 24/7 kể cả khi bạn tắt máy tính cá nhân, bạn có thể triển khai bộ công cụ này lên Máy ảo (VPS Ubuntu / Windows) hoặc Docker:

Cách 1: Khởi tạo Máy ảo Linux (Ubuntu 22.04 / 24.04 VPS) — Nhẹ & Ổn định nhất

Thuê 1 VPS Ubuntu (từ 2 CPU / 2GB RAM trở lên). Copy thư mục dự án lên VPS và chạy lệnh tự động:

chmod +x setup-vps-ubuntu.sh && ./setup-vps-ubuntu.sh

Cách 2: Chạy bằng Docker Container (1 lệnh duy nhất)

docker compose up -d --build

Cách 3: Mở App trực tiếp trên màn hình Desktop Windows

Nhấp đúp vào biểu tượng "YouTube Live Manager" ngoài màn hình Desktop (hoặc file Open-Desktop-App.vbs) để mở cửa sổ phần mềm độc lập.
